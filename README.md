# Trabalho Prático - Pilhas e Filas (EDAA 2026)

Este repositório contém a implementação prática de duas estruturas de dados lineares fundamentais:
1. **Navegador Web (Pilhas):** Controle dos botões avançar e voltar utilizando duas pilhas lógicas.
2. **Sistema de Senhas (Filas):** Gerenciador de atendimento hospitalar com controle de ordem de chegada (FIFO) e histórico de chamadas.

## Como Executar o Projeto
Certifique-se de ter o Java JDK instalado. Compile e execute o arquivo principal via terminal:
